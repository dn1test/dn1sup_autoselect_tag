# Changelog (Лог изменений)

Лог изменений **DN1Sup AutoSelect Tag** (`dn1sup_autoselect_tag`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.6.8] — 2026-10-26

### DN1Sup AutoSelect Tag (v0.6.8)
- **Отдельный тулбар всегда.** Удалена зависимость от общей панели DN1Sup:
  тулбар расширения создаётся всегда, без проверки параметра
  «Показывать отдельные тулбары расширений» в менеджере.

## [0.6.7] — 2026-10-19

### DN1Sup AutoSelect Tag (v0.6.7)
- **Статусная строка в окне настроек** — в самом низу окна: контекстные
  подсказки (зависят от поля в фокусе или кнопки под курсором) и состояние
  работы («Готов · правил: N», «Сохранение…», «Проверка обновлений…»).
- **Работа приложения в статус-баре SketchUp** — автоназначение тегов и
  массовое применение правил пишут итог («назначено тегов: N»,
  «перенесено в теги: N»); сохранение настроек тоже отмечается.
- **Справка и бейдж версии** — кнопка «?» в шапке открывает окно справки,
  рядом с названием показан номер версии.
- Исправлен вызов массового применения правил после сохранения настроек
  (`offer_retag` теперь идёт через `AutoSelectTag.retag_existing`).

## [0.6.6] — 2026-10-18

### DN1Sup AutoSelect Tag (v0.6.6)
- **Тулбар не создаётся, когда работает общая панель DN1Sup.** Пока в
  менеджере выключен параметр «Показывать отдельные тулбары расширений»
  (по умолчанию), свой тулбар не создаётся — его нет и в списке панелей
  SketchUp (View → Toolbars). Кнопка «Настройки» остаётся на общей
  панели и в меню DN1Sup. Заодно выровнена версия в MANIFEST
  (0.6.4 → 0.6.6; в 0.6.5 подняли только лоадер).

## [0.6.5] — 2026-10-17

### DN1Sup AutoSelect Tag (v0.6.5)
- **Обновление — только из GitHub.** Кнопки проверки и фоновая проверка при
  старте переведены с `check_local_first!` на `check!`; `dev_dir` удалён из
  манифеста. Копия общего апдейтера обновлена до v5 (единая копия для всех
  расширений DN1Sup: локальные источники удалены, для менеджеров старых
  версий оставлены заглушки совместимости, status_cb-прогресс сохранён).
## [0.6.4] — 2026-10-16

### DN1Sup AutoSelect Tag (v0.6.4)
- **Фирменная плитка DN1Sup в шапке GUI** — та же плитка, что в каталоге
  Extension Store (цветной квадрат, знак с «воздухом»); работает в светлой
  и тёмной теме. Источник — `dn1sup_extensions` (`tools/make_icons.rb`).
## [0.6.3] — 2026-10-16

### DN1Sup AutoSelect Tag (v0.6.3)
- **Фирменный знак тулбара DN1Sup** — единый стиль каталога Extension
  Store: бирка с искрой «авто» (violet), прозрачный фон, вырезы — настоящая прозрачность
  (SVG-маска; PNG 16/24 — альфа-канал). Источник знака —
  `dn1sup_extensions` → `icons/products/` (`tools/make_icons.rb`).


## [0.6.2] — 2026-10-16

- Добавлен тулбар «DN1Sup AutoSelect Tag» с иконкой `icons/tag.svg`
  (бирка = теги, искра на бейдже = авто); кнопка открывает диалог настроек
  (как пункт меню «Настройки...»). Защита от дублей по tooltip, `toolbar.restore`.

## [0.6.1] — 2026-10-16

- Убран переходный маркер `.sketchup_dev.json` из `dev_source?` (период
  миграции со старых `_dev`-установок завершён); self-update рабочей копии
  определяется только по пути загрузки (код вне папки `Plugins`).

## [0.6.0] — 2026-10-15

- Удалён функционал dev/prod (второй id `dn1sup_autoselect_tag_dev`): удалены
  `DEV_BUILD`, поле `dev_build` в данных диалога и бейдж DEV в шапке настроек.
  Разработка — рабочая копия под тем же id с перезагрузкой
  `Dn1sup::AutoSelectTag.reload`; self-update рабочей копии отключён по пути
  загрузки (`Dn1sup::Updater.dev_source?`); файлы `.sketchup_dev.json` удалены.
- Обновления: единый апдейтер v3 — проверка сначала смотрит папку разработки,
  потом GitHub (`check_local_first!`, `dev_dir` в MANIFEST); кнопка проверки
  обновлений в шапке диалога настроек (`check_update`); фикс кодировки UTF-8
  при чтении registry.json/CHANGELOG.md с GitHub.
- Чистка: удалены `archive/`, старые `.rbz` в `dist/`, `tools/list_rbz.rb`;
  `author` добавлен в `registry.json`.
