Теги автоназначения
Правила по имени компонента

Компонент, в имени экземпляра или определения которого есть любое из слов-триггеров (без учёта регистра), переносится в тег правила. Правила проверяются сверху вниз — первое совпадение выигрывает.

Выберите существующий тег из списка или впишите новое имя — тег создастся при первом назначении.
